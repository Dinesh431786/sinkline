What it is for

A secret leaves one file and lands in a sink three files away. Review never catches that.

Sinkline draws the line. It follows tainted data from source to sink across a whole project and reports the path — along with the things a single-file linter has no rule for: logic bombs on a probabilistic trigger, base64 payloads inside a “plugin loader”, install hooks that fire on pip install, typosquatted dependencies, and keys that only matter because boto3 is imported beside them.

Every engine is deterministic and runs on this machine. Same input, same result, no network.
